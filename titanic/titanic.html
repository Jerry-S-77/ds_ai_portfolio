O Danych¶

Dane o pasażerach Titanica

Zbiór danych zawiera informacje o pasażerach RMS Titanic, który zatonął 15 kwietnia 1912 roku po zderzeniu z górą lodową. Dane obejmują takie atrybuty jak klasa podróży, wiek, płeć, liczba rodzeństwa/małżonków na pokładzie, liczba rodziców/dzieci na pokładzie, cena biletu oraz miejsce zaokrętowania.

Zbiór zawiera także informację o tym, czy pasażer przeżył katastrofę.

Titanic przewoził ponad 2,200 osób, z czego ponad 1,500 zginęło, co czyni tę katastrofę jedną z najbardziej tragicznych w historii morskiej.

Kolumny:

  • pclass - Klasa biletu
  • survived - Czy pasażer przeżył katastrofę
  • name - Imię i nazwisko pasażera
  • sex - Płeć pasażera
  • age - Wiek pasażera
  • sibsp - Liczba rodzeństwa/małżonków na pokładzie
  • parch - Liczba rodziców/dzieci na pokładzie
  • ticket - Numer biletu
  • fare - Cena biletu
  • cabin - Numer kabiny
  • embarked - Port, w którym pasażer wszedł na pokład (C = Cherbourg, Q = Queenstown, S = Southampton)
  • boat - Numer łodzi ratunkowej
  • body - Numer ciała (jeśli pasażer nie przeżył i ciało zostało odnalezione)
  • home.dest - Miejsce docelowe

def age_category(age):
    if pd.isnull(age):
        return 'brak danych'
    elif age < 12:
        return '0-11'
    elif age < 18:
        return '12-17'
    elif age < 30:
        return '18-29'
    elif age < 45:
        return '30-44'
    elif age < 60:
        return '45-59'
    else:
        return '60+'

7. WNIOSKI KOŃCOWE¶

Szanse na przeżycie katastrofy Titanica zdecydowanie nie były równe.

  1. Przeżyło ok. 38% pasażerów, czyli niewiele ponad co trzecia osoba.
  2. Najwięcej znaczyła płeć – przeżyło ok. 73% kobiet i tylko ok. 19% mężczyzn.
  3. Zaraz potem klasa. Im wyższa, tym większa szansa, a w 3 klasie przeżyła mniej więcej co czwarta osoba.
  4. Dzieci miały lepsze szanse niż dorośli, ale znowu – dzieci z 3 klasy dużo gorsze niż z 1 i 2.
  5. Cena biletu i port na początku wyglądały na ważne, ale po sprawdzeniu okazało się, że to w dużej mierze ta sama klasa.
  6. Najlepiej wypadły małe rodziny (2-4 osoby). Osoby samotne i duże rodziny miały znacznie mniejsze szanse.

Największą szansę przeżycia miały:¶

  1. kobiety
  2. osoby z 1 klasy (zamożne)
  3. dzieci

Najbardziej zaskoczyło mnie, że kobiety z 3 klasy przeżyły tylko w połowie – zasada „najpierw kobiety i dzieci” nie dotyczyła wszystkich w tym samym stopniu.

Trzeba pamiętać, że brakuje wieku dla ok. 20% pasażerów (głównie z 3 klasy), więc wnioski o wieku są przybliżone.
