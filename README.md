# Portfolio – Jerzy Śliwa

Strona: https://jerry-s-77.github.io/ds_ai_portfolio

Moje projekty z analizy danych i AI w utrzymaniu ruchu. Strona zbudowana w `mkdocs` z motywem `mkdocs-material`,
tak jak w kursie „Od zera do AI” (moduł 12).

## Uruchomienie lokalne

```bash
conda activate od_zera_do_ai
conda install -y conda-forge::mkdocs conda-forge::mkdocs-material
mkdocs serve
```

## Publikacja

```bash
mkdocs gh-deploy
```
